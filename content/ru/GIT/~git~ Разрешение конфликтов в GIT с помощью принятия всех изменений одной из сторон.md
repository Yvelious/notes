Когда, например, возникает конфликт между двумя файлами, и нет смысла вручную разрешать конфликт построчно, можно полностью принять изменения одной из сторон. Для этого используются следующие команды:

Принять изменения с чужой стороны
```bash
git checkout --theirs .
git add .
```

Принять изменения со своей стороны
```bash
git checkout --ours .
git add .
```

**N.B.**
Точка (`.`) в конце команды означает, что операция применяется ко всем конфликтующим файлам. Если нужно применить команду к конкретному файлу, указывайте вместо точки путь к этому файлу.
